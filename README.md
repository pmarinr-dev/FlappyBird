# Flappy Bird en Jack (Nand2Tetris)

## Créditos de Autoría
* Juan Pablo Marín Rondón

## Instrucciones de Compilación
1. Abrir la consola de comandos.
2. Ejecutar el compilador Jack apuntando al directorio del proyecto: `JackCompiler.bat ruta/a/la/carpeta`.

## Instrucciones de Ejecución
1. Abrir el `VMEmulator`.
2. Cargar el directorio del proyecto usando el botón "Load Program".
3. Desactivar las animaciones (Animate: "No animation") y ajustar la velocidad al máximo (Speed: "Fast").
4. Presionar "Play".

## Controles
* **Barra Espaciadora**: Saltar / Volar.
